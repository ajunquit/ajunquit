## En pocas palabras

Soy ingeniero de software con experiencia en sistemas empresariales para banca, aerolíneas, facturación electrónica, gestión documental, GRC y servicios financieros.

Trabajo **hands-on** y con visión end-to-end: diseño arquitectura, escribo y reviso código, automatizo pruebas y despliegues, acompaño incidentes de producción y ayudo a que el equipo tome mejores decisiones técnicas. Mi foco está en modernizar plataformas críticas sin perder de vista mantenibilidad, seguridad ni velocidad de entrega.

## En lo que estoy trabajando actualmente

- **Platform engineering con .NET:** bases reutilizables sobre .NET 10, Aspire, PostgreSQL y Keycloak; monolitos modulares con Clean Architecture, DDD, CQRS, multi-tenancy y contratos entre módulos.
- **Aplicaciones y plantillas Angular:** Angular 20, TypeScript y Tailwind; configuración en runtime, componentes reutilizables y una base consistente para nuevos productos.
- **DevOps como parte de la arquitectura:** CI/CD, Docker, Terraform, quality gates, artefactos OCI inmutables y contratos claros entre aplicaciones e infraestructura.
- **Cloud y mensajería multiproveedor:** Azure Container Apps, Azure Service Bus, ACR y Application Insights; AWS SNS/SQS y una estrategia portable basada en outbox/inbox, también compatible con RabbitMQ.
